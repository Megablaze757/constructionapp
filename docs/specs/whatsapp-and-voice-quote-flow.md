# Spec: One-Tap WhatsApp Quote Sharing & Voice-First Creation

## 1. Problem Statement
Non-technical UK builders (like Daz and Macca) lose jobs because quote creation requires complex typing and sending quotes to clients requires manually copying/pasting URLs. They communicate primarily via WhatsApp on mobile phones and need a one-tap action to dispatch interactive quotes immediately after leaving a site.

## 2. Success Criteria
- [ ] A prominent, primary green **"Send via WhatsApp"** button appears on `builder.html` whenever a valid quote link exists.
- [ ] Tapping "Send via WhatsApp" opens native WhatsApp on iOS/Android with a pre-filled, professional client message and quote link.
- [ ] The Quote Builder input area features a prominent **"Tap to Speak Quote"** button with clear visual recording feedback.
- [ ] Complete flow (voice record → AI draft → WhatsApp send) can be executed in under 30 seconds on a mobile phone.

## 3. User Flow
1. **Record**: Builder taps large **"Tap to Speak Quote"** button on `builder.html` and speaks site details (*"Rear scaffold, 2 lifts, roofer access 5 days"*).
2. **Draft**: Builder taps **"Generate Draft"**; AI populates line items and calculates prices via price book.
3. **Review**: Builder reviews margin badge (`#margin-badge`) and total.
4. **Dispatch**: Builder taps large green **"Send via WhatsApp"** button (`#whatsapp-share-btn`).
5. **Client Inbox**: WhatsApp opens with pre-populated message: *"Hi [Client Name], here is your quote for [Site Address]: [Quote URL]. Let me know if you have any questions!"*

## 4. Screens Affected
- `web/builder.html` — Add `#whatsapp-share-btn` in action bar; enlarge `#record-btn` UI.
- `web/assets/js/builder.js` — Implement WhatsApp URI scheme handler (`https://wa.me/?text=...` / `whatsapp://send?text=...`).
- `web/index.html` — Add quick WhatsApp resend button next to recent quotes in list view.
- `web/assets/js/list.js` — Wire WhatsApp share action on quote list items.

## 5. Data Changes
- None to database schema. Uses existing `public_url` / quote ID token parameters generated by Worker / local WASM.

## 6. Edge Cases
- **Client Phone Number Missing**: If client phone number is unentered, open WhatsApp contact selector with pre-filled text (`https://wa.me/?text=...`). If phone number exists, pre-target number directly (`https://wa.me/[phone]?text=...`).
- **No WhatsApp Installed / Desktop Browser**: Fall back gracefully to `navigator.share()` API or clipboard copy with toast notification *"Quote link copied!"*.
- **Voice Recognition Unsupported**: Fall back seamlessly to standard textarea input.

## 7. What We Are NOT Changing
- Not altering backend price book calculation logic in `worker/src/pricing.js`.
- Not modifying client signature or interactive quote acceptance flow on `web/quote.html`.
- Not introducing native app dependencies; strictly web-standard URI schemes.
